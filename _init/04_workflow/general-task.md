# 04 · 작업 방식 — 일반 task

> ⚠️ **최고 규칙(_init) — 일반 task 중 변경 금지.** 개정은 명시적 승인으로만.
> 상위: [../04_workflow.md](../04_workflow.md) W1~W3 공통 게이트를 먼저 따른다.

코드·문서 작성 외의 작업(조사·분석·운영·검색·요약·실행 등)의 워크플로우.

## GT1. 자유 실행 범위

- 조사·분석·읽기·검색·요약·메모리 저장은 **승인 없이** 진행할 수 있다.
- 결과는 사실대로 보고한다(W3). 불확실하면 확신도를 밝힌다.

## GT2. 승인 게이트 (부수 효과)

- 일반 task라도 **파일을 만들거나 바꾸는 단계**가 생기면 W1(제안 후 실행)을 적용한다.
- **되돌리기 어렵거나 외부로 나가는 작업**(푸시·삭제·전송·외부 서비스 게시)은 사전 확인한다(W3).

## GT3. `_init` 불변

- 일반 task 중에는 `_init` 폴더를 변경하지 않는다([../00_governance.md](../00_governance.md) G2). 규칙이 부족하면 하위 문서에서 확장한다.

## GT4. 대상 자료 확인

- 삭제·덮어쓰기 전에는 대상을 실제로 확인하고, 설명과 다르거나 내가 만들지 않은 것이면 진행 대신 먼저 알린다.
