# 00 · 거버넌스 — `_init`의 권위와 불변성

> ⚠️ **최고 규칙(_init) — 일반 task 중 변경 금지.** 개정은 명시적 승인으로만.

## G1. 최고 권위

`_init`의 규칙은 레포 내 모든 문서·스킬·컨벤션보다 상위다. 어떤 하위 문서도 `_init`과 상충하는 규칙을 둘 수 없다(MUST NOT). 상충이 발견되면 `_init`이 이기고, 하위 문서를 고친다.

## G2. 불변성 (일반 task 중 변경 금지)

- 일상적인 작업(코드 작성·문서 정리·스킬 실행·리뷰 등) 중에는 `_init` 폴더의 파일을 **생성·수정·삭제하지 않는다(MUST NOT)**.
- 하위 규칙이 부족하면 `_init`을 바꾸지 말고 **하위 문서에서 확장**한다. `_init`은 최소한의 최고 원칙만 담는다.

## G3. 개정 절차 (예외적 변경)

`_init`을 바꾸려면 다음을 모두 만족해야 한다.

1. 사용자가 **명시적으로 `_init` 개정을 요청**했다(일반 task 지시로는 불가).
2. [04_workflow.md](./04_workflow.md)의 제안 후 실행 게이트를 거친다 — 변경안을 제안하고 승인받은 뒤 반영.
3. 변경은 [03_authoring.md](./03_authoring.md) 버전 규칙에 따라 이력을 남긴다.

## G4. 적용 범위

- 적용 대상: 이 레포의 모든 규칙 문서(`code-conventions/`, `_template/_conventions/`, `working-agreements/`)와 스킬.
- 각 하위 규칙 문서는 상단에 `> Governed by [_init](경로)` 배너를 둔다.
