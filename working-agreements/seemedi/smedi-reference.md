# 회사명 표기 (SEEMEDI AI / SMEDI) — SEEMEDI 특이

> **SEEMEDI 특이** — 회사 참조 사실. 출처: `reference_company-name-smedi`.

회사명은 **SEEMEDI AI**, 약칭은 **SMEDI**다.
`CMEDI` · `CMED AI` · `SMED AI`는 모두 **잘못된 표기**이므로 문서·코드 어디에도 쓰지 않는다.
이메일 도메인은 `seemedi.com` (예: nayeon@seemedi.com).

| 용도 | 표기 |
|------|------|
| 문서 헤더/표시명 | `SEEMEDI AI` (배너: `씨메디에이아이 (SEEMEDI AI)`) |
| 약칭 | `SMEDI` |
| 코드 네임스페이스 토큰 | `seemedi` → [../../code-conventions/seemedi/by-task/seemedi-namespace.md](../../code-conventions/seemedi/by-task/seemedi-namespace.md) |

> 코드에서는 `smedi`/`cmed` 토큰을 쓰지 않는다. 실제 도메인 `seemedi.com`과 정합.
