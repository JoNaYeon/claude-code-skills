# 문서 형식 컨벤션

> 문서 작성·버전 관리 형식 규칙을 **General**과 **SEEMEDI 특이**로 분리한 모음입니다.
> 근거: SEEMEDI `STD-DOC-0001`, `STD-VER-0001`, 전사베이스 vault 관행.

## `general/` — 재사용 가능
| 문서 | 내용 |
|------|------|
| [document-versioning](./general/document-versioning.md) | `_vN` 버전 규칙, 부분개정/전체개정 |
| [frontmatter-and-naming](./general/frontmatter-and-naming.md) | frontmatter 스키마, 파일명, 폴더 안내 파일 |

## `seemedi/` — SEEMEDI 특이
| 문서 | 내용 |
|------|------|
| [smedi-document-standards](./seemedi/smedi-document-standards.md) | STD 문서 ID 체계, docx 스타일, 배너, v1 폴더 보존 |

## 사용 규칙
- General 형식 규칙은 어느 프로젝트 문서에도 적용 가능.
- SEEMEDI 전사베이스 문서는 seemedi 규칙을 추가 적용.
